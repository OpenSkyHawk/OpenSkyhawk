    variable ATTEMPTS_BKP_REGISTER

    constexpr uint8_t OpenSkyhawk::Boot::ATTEMPTS_BKP_REGISTER;

    Crash-loop counter (#364): the bootloader adds one before every jump to the app; the app sets it back to 0 once it is healthy (STM32Board::markBootHealthy()). At ATTEMPT_LIMIT the bootloader stays (BootState::APP_UNSTABLE). Cleared by a committed image; lost on a power cycle.

    The app sets backup register DR1 to ENTRY_MAGIC and resets to enter the bootloader (#365). The bootloader clears it on read. The backup domain survives a reset, not a power cycle.

    variable UNCONFIGURED_CMD_ID

    constexpr uint16_t OpenSkyhawk::Boot::UNCONFIGURED_CMD_ID;

    Commands to an unconfigured bootloader (#364). CONNECT names the board's UID hash (AnnounceField::UID16); only that board binds the session and answers on UNCONFIGURED_RSP_ID. One unconfigured board on the bus at a time.

    variable UNCONFIGURED_RSP_ID

    A bootloader with no NODE_ID yet (option byte Data0 = 0xFF, no valid app) announces here. 

    constexpr uint16_t OpenSkyhawk::Boot::UNCONFIGURED_RSP_ID;

    variable WINDOW_BLOCKS

    constexpr uint8_t OpenSkyhawk::Boot::WINDOW_BLOCKS;

    Blocks a host may send ahead of the last ack (#366). The bootloader buffers their frames while it writes flash; a lost block is resent from BLOCK_ACK's next (go-back-N). BEGIN erases every page the image needs before it replies, so no erase stalls the stream.
