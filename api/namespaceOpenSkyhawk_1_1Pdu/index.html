    function currentMa

    Rail current in mA from the INA180 output voltage. 

    int32_t OpenSkyhawk::Pdu::currentMa (
    uint32_t adcMv,
    int16_t zeroDmA,
    uint16_t iGain
)

    Parameters:

    • adcMv INA180 output at the ADC pin, mV.
    • zeroDmA Zero offset to subtract, 0.1 mA (from CAL ZERO).
    • iGain Gain trim, 10000 = ×1.

    Returns:

    Signed mA — a small negative value is residual offset, kept so it stays visible.

    function ntcTempDC

    Board temperature in 0.1 °C from the NTC channel (ratiometric — VDDA cancels). 

    int16_t OpenSkyhawk::Pdu::ntcTempDC (
    uint16_t counts,
    int16_t offsetDC,
    bool & fault
)

    Parameters:

    • counts 16-bit ADC count of the NTC node.
    • offsetDC One-point offset, 0.1 °C.
    • fault Set true when the reading is outside 2–98 % of full scale (open / shorted NTC).

    Returns:

    Temperature in 0.1 °C, or NTC_TEMP_UNAVAILABLE (NodeStatus.h) when fault.

    function vddaMv

    VDDA in mV from a raw Vrefint reading. 

    uint16_t OpenSkyhawk::Pdu::vddaMv (
    uint16_t vrefintRaw,
    uint16_t vrefintMv
)

    Parameters:

    • vrefintRaw 16-bit ADC count of the internal reference (0 = unreadable).
    • vrefintMv This chip's calibrated Vrefint, or 0 when uncalibrated.

    Returns:

    VDDA in mV: Vrefint-tracked when calibrated, VDDA_NOMINAL_MV otherwise (the untrimmed F103 Vrefint is a worse reference than the regulator's nominal until anchored).
